# Arno Blocks

My portfolio as a 2D block world. My work is buried as ore, newest near the surface and older work deeper. Hold on a block to mine it; digging up an ore opens that project or job. The sign at the surface is the About page and the chest holds my contact details and CV. Right-click places blocks from the hotbar, and there's a day/night toggle.

Built with TypeScript, HTML canvas and CSS, using Vite. No framework; every block texture is painted in code.

## Run it

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

## Content

All personal content lives in `src/data.ts`, mirrored from my main portfolio ([Chrome-portfolio](https://github.com/Arno-Boenders/Chrome-portfolio)). Screenshots and the CV are in `public/`.
